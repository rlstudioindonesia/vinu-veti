# Logo aplikasi

1. Simpan logo persegi (min. 1024×1024 px) sebagai `branding/app-logo.png` (sudah ada).
2. Jalankan `tools/make-android-icon.sh` (butuh ImageMagick).
   Semua ikon launcher Android + `branding/playstore-icon-512.png` (ikon listing Play Store) dibuat otomatis.

# Maskot homepage

Simpan gambar maskot Vinu & Veti (PNG latar transparan) sebagai `web-app/public/mascot.png`,
lalu jalankan `npm run build` di folder `web-app`. Homepage menampilkannya otomatis.
