# Konten Online di Cloudflare R2

Sejak versi 16, konten (model 3D, suara, gambar) disimpan di **Cloudflare R2** dan disajikan oleh Worker
aplikasi ini (`worker/index.js`), di alamat yang sama dengan versi web:
`https://vinu-veti.linggadhani79.workers.dev/cdn/…`. Login admin & Publikasikan juga lewat Worker itu.

Kenapa: paket gratis Supabase hanya memberi 5 GB unduhan per bulan, sedangkan konten ±550 MB per HP.
**Unduhan dari R2 tidak dikenai biaya** (paket gratis R2: 10 GB penyimpanan).

## Sekali saja di dashboard Cloudflare

1. **R2 Object Storage** → aktifkan R2 (bila diminta menambah metode pembayaran: paket gratis tetap
   gratis selama di bawah batasnya) → **Create bucket** → nama persis: `vinu-veti-konten` → Create.
2. **Workers & Pages → vinu-veti → Settings → Variables and Secrets → Add**:
   - Type: **Secret**, Name: `ADMIN_USERS`
   - Value: akun admin, format `nama:password` (nama boleh email atau kata biasa), beberapa akun
     dipisah koma, contoh `admin:SandiPanjangYangKuat123,guru@sekolah.id:SandiLain456`
   - Letaknya di **Settings → Variables and Secrets** milik Worker (bukan variabel di bagian Build).
   - Save. (Ganti password = ubah secret ini; semua admin otomatis keluar.)
3. Merge PR ini → Cloudflare membangun & memasang Worker baru (binding R2 `CONTENT` sudah diatur di
   `wrangler.jsonc`). **Bucket harus sudah ada sebelum merge**, kalau tidak pemasangan gagal.

## Memindahkan konten yang sudah ada (tanpa unggah ulang satu per satu)

- Buka menu admin di PC yang dipakai membuat konten → login (akun dari langkah 2) → **Publikasikan**.
  File yang tersimpan di browser itu diunggah otomatis; file yang sudah ada di R2 dilewati.
- File yang tidak ada di PC itu disalin Worker **sendiri** dari Supabase saat pertama diminta
  (`LEGACY_CONTENT_URL` di `wrangler.jsonc`) — begitu Supabase tidak terblokir lagi.
- Bila Publikasikan melaporkan file tidak bisa diambil dan Supabase masih terblokir: **Impor Paket
  Konten** dari ZIP cadangan (Ekspor Paket Konten) di PC itu, lalu Publikasikan lagi.

HP yang sudah punya konten **tidak mengunduh ulang**: file dikenali dari SHA-256, alamatnya saja yang
berubah. Sampai Publikasikan pertama ke R2, HP tetap memakai konten yang sudah tersimpan.

## Catatan

- Batas gratis Worker: 100.000 permintaan/hari (unduhan berjalan per potongan 4 MB, ±140 permintaan
  untuk konten 550 MB per HP). Batas gratis R2: 10 GB, 1 juta tulis & 10 juta baca per bulan.
- Satu unggahan maksimal 100 MB (file besar otomatis dipecah 45 MB).
- `docs/SUPABASE.md` hanya untuk sejarah / aplikasi versi lama.
