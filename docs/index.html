Kebijakan Privasi (Privacy Policy)

1. Pendahuluan

Kami menghormati dan berkomitmen untuk melindungi privasi pengguna aplikasi Vinu Veti. Kebijakan Privasi ini menjelaskan bagaimana aplikasi kami mengelola akses perangkat, data, dan privasi Anda sesuai dengan standar Google Play Developer Program Policy.

2. Penggunaan Akses Kamera (Camera Permission)

Aplikasi ini meminta izin akses kamera perangkat (android.permission.CAMERA) semata-mata untuk fungsi inti Augmented Reality (AR):

  • Tujuan Utama: Menangkap streaming video langsung untuk mendeteksi stiker kode QR pada buku fisik dan memproyeksikan objek 3D interaktif (.GLB) di atas halaman buku secara waktu nyata (real-time).
  • Pemrosesan Lokal di Perangkat (On-Device Processing): Semua pemindaian citra kamera dilakukan 100% secara lokal pada prosesor perangkat pengguna.
  • Tidak Ada Perekaman: Aplikasi TIDAK menyimpan, merekam, mengambil foto, maupun menyiarkan gambar/video kamera ke server mana pun.

3. Penyimpanan Data & File 3D (.GLB / Audio)

Aplikasi ini dirancang dengan prinsip Offline-First:

  • File model 3D (.GLB/.GLTF) dan file audio yang diunggah oleh pengguna disimpan secara lokal di ruang penyimpanan privat aplikasi (context.filesDir/ar_models/) dan database lokal (IndexedDB).
  • Tidak ada izin penyimpanan luas berbahaya (seperti READ_EXTERNAL_STORAGE atau MANAGE_EXTERNAL_STORAGE) yang diminta. Kami sepenuhnya mematuhi kebijakan Scoped Storage Google Play.
  • Data Anda tidak pernah diunggah ke internet atau dibagikan ke pihak ketiga.

4. Pengumpulan & Pembagian Data Pribadi

Aplikasi AR Book Explorer TIDAK mengumpulkan informasi identitas pribadi (PII), seperti nama, nomor telepon, alamat email, lokasi GPS, maupun data perbankan. Kami tidak menggunakan SDK analitik invasif atau pelacak iklan pihak ketiga.

5. Privasi Anak-Anak (Children's Privacy / COPPA & GDPR-K)

Karena aplikasi ini dapat digunakan dalam konteks edukasi buku sekolah dan anak-anak, kami secara tegas mematuhi Children's Online Privacy Protection Act (COPPA) dan kebijakan Google Play Families:

  • Kami tidak secara sengaja mengumpulkan data apa pun dari anak-anak di bawah usia 13 tahun (atau batas usia yang berlaku di wilayah Anda).
  • Semua interaksi AR bersifat edukatif dan berjalan secara offline.

6. Penghapusan Data (Data Deletion)

Pengguna memiliki kendali penuh atas data mereka. Anda dapat menghapus setiap stiker QR, model 3D, atau audio yang tersimpan kapan saja melalui tombol Hapus di panel Admin aplikasi, atau dengan menghapus data aplikasi melalui Pengaturan Android.
